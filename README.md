# TwitchCircus

this is a simple python script to enable obs to spawn content from a twitch channel
it uses the twitch api in order to subscribe to a channel events

if you want to use this script, you need to create a twitch app and get the client id and secret
you can do this by going to the twitch developer console and creating a new app

## requirements

python 3.12 or higher

install the requirements using pip:
```bash
pip install -r requirements.txt
```
